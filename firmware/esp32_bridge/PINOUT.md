# Распиновка ESP32-S3

Плата: ESP32-S3-DevKitC-1 (или совместимая). Номера — GPIO, как подписаны на плате.
Значения в коде — `include/config.h`.

```
                         ESP32-S3-DevKitC-1
                       ┌───────────────────┐
                 3V3 ──┤ 3V3          GND  ├── GND
                       │                   │
   MPU6050 SDA ────────┤ GPIO 8            │
   MPU6050 SCL ────────┤ GPIO 9            │
                       │                   │
   Гироскутер TX ──────┤ GPIO 18 (RX)      │      HB_RX_PIN
   Гироскутер RX ──────┤ GPIO 17 (TX)      │      HB_TX_PIN
                       │                   │
   Лидар TX ───────────┤ GPIO 32 (RX)  ⚠   │      LIDAR_RX_PIN  — см. ниже
   (не нужен)  ────────┤ GPIO 33 (TX)  ⚠   │      LIDAR_TX_PIN
                       │                   │
                       │  [USB]   [UART]   │  ← ПК (сборка usb) — в порт «USB»
                       └───────────────────┘
```

## Подключения

| Устройство | Вывод устройства | ESP32-S3 | Примечание |
|---|---|---|---|
| **MPU6050** | VCC | 3V3 | Модули GY-521 работают и от 3.3 В |
| | GND | GND | |
| | SDA | **GPIO 8** | |
| | SCL | **GPIO 9** | |
| | AD0 | GND или не подключать | адрес 0x68 |
| **Плата гироскутера** (кабель сайдборда, USART2/USART3 прошивки FOC) | TX | GPIO 18 | 3.3 В логика |
| | RX | GPIO 17 | |
| | GND | GND | общая земля обязательна |
| | **15 В** | **не подключать!** | на разъёме сайдборда есть 15 В — сожжёт ESP32 |
| **Лидар пылесоса** | TX (данные) | GPIO 32 ⚠ | см. предупреждение |
| | RX | — | лидару команды не нужны |
| | 5V / GND | внешние 5 В / GND | питание лидара и мотора — не с пина 3V3 ESP32 |
| **ПК** (сборка `usb`) | USB-кабель | порт «USB» платы | на ПК — `/dev/ttyACM0` |

Питание ESP32: от USB (сборка `usb`) или 5 В на пин 5V от DC-DC с батареи гироскутера.
Земли всех устройств должны быть соединены.

## Почему именно эти пины

У ESP32-S3 нельзя использовать:

| GPIO | Чем занят |
|---|---|
| 0, 3, 45, 46 | выбор режима загрузки — внешняя нагрузка может помешать старту |
| 19, 20 | встроенный USB (через него идёт связь в сборке `usb`) |
| 26–32 | флеш-память модуля |
| 33–37 | PSRAM на модулях с 8 МБ PSRAM (маркировка …R8) |
| 43, 44 | UART0 — порт «UART» платы |
| 22–25 | у ESP32-S3 этих выводов нет |

Свободны и безопасны: **1, 2, 4–18, 21, 38–42, 47, 48**.

## ⚠ Лидар на GPIO 32/33

Пины лидара взяты из старой прошивки, но GPIO 32 у ESP32-S3 — линия флеш-памяти.
Проверьте, к какому выводу реально подключён провод данных лидара.
Если он действительно на 32 — переткните на свободный пин, например
**GPIO 4 (RX)** и **GPIO 5 (TX)**, и поменяйте в `include/config.h`:

```cpp
constexpr int LIDAR_RX_PIN = 4;
constexpr int LIDAR_TX_PIN = 5;
```
