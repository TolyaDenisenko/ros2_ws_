# Hoverbot изнутри

### Учебник по роботу на шасси гироскутера: прошивки, протокол, ROS 2-ноды, симуляция, SLAM и навигация

Эта книга — путеводитель по коду репозитория `ros2_ws_`. Она объясняет,
**что** делает каждая часть робота, **как** это написано в коде и **как это
настроить**, чтобы робот поехал и построил карту.

## Для кого

Для инженера, который знает C++ и основы Linux, слышал про ROS 2, но
впервые видит этот проект. Опыт с микроконтроллерами желателен, но не
обязателен: всё, что касается ESP32 и STM32, объясняется с нуля.

## Соглашения

- Пути даны от корня рабочего пространства `~/ros2_ws_`.
- `файл.cpp:120` — строка в файле; номера могут уплыть после правок,
  ориентируйтесь по имени функции.
- Блоки **⚠ Внимание** — то, что может сжечь железо или незаметно сломать
  систему. Блоки **✎ Упражнение** — короткие задания для проверки себя.
- ROS-дистрибутив: на машине разработчика стоит **Kilted** + Gazebo Sim 9,
  код рассчитан и на Jazzy. Во всех командах подразумевается
  `source /opt/ros/kilted/setup.bash && source install/setup.bash`.

## Состояние проекта

Симуляция, SLAM и Nav2 проверены в Gazebo. На реальном железе связка
**не запускалась**: есть известные несоответствия (скорость UART, пины лидара),
о них честно сказано в главах 2, 3 и 10. Актуальный статус — в
[../CHECKLIST.md](../CHECKLIST.md).
